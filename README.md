# Natalia Marinho — sitio estático

Portafolio HTML de una sola página. La entrada de despliegue es `index.html` y los recursos visuales permanecen locales.

## Validación local

```powershell
npm test
python -m http.server 8080
```

Abrir `http://localhost:8080`. El smoke test comprueba la entrada, los activos locales, la navegación móvil, enlaces externos y reducción de movimiento.
